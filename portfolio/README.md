# Portfolio

Case studies of real, delivered work, and clearly labelled concept builds.

## Rules

- **Client projects only with written permission** from the client. If they prefer, describe them without naming them ("a Nashik bakery").
- Practice or demo builds are labelled **Concept**, everywhere.
- Screenshots come from the real, working build. No mock-ups shown as live work.
- Results must be real and checkable. No invented numbers.

## Adding a case study

1. Copy [case-study-template.md](case-study-template.md) to `portfolio/<project-name>/README.md`.
2. Put screenshots in the same folder (WebP or PNG, 1600 px wide).
3. Add the project to the website: [website/data/projects.js](../website/data/projects.js), and copy one screenshot to `website/assets/work/`.
