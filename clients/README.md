# Clients

One folder per client project.

## Start a new client

Copy [`_template/`](_template/) to `clients/<client-name>/` (lowercase, hyphens: `clients/sai-dental-nashik/`). Then fill in the files in order:

| File | When |
|---|---|
| `01-brief.md` | After the first call. Get the client to confirm it |
| `02-quote.md` | When the quote is accepted (copied from `proposals/`) |
| `03-delivery-note.md` | At handover |
| `04-change-log.md` | Every time a change is requested |

## Privacy

Client folders can contain personal or business details. **Don't commit passwords, API keys or customer data.** Keep logins in a password manager, not in this repo. If a client's details shouldn't be on GitHub at all, keep that folder outside the repo, or keep the repo private.
