## Editing a post

1. Open the batch HTML file in a browser to see all posts.
2. Edit the text in the HTML.
3. Re-export the PNGs. Any headless browser screenshot of each `section.post` element at 1080 × 1350 works.

## Rules (Quality Framework §7)

- Jokes target situations, never religion, caste, region, gender, or real people or companies.
- Only real numbers and real client work. Concept work is labelled.
- Every post ends with a way to reach us.
