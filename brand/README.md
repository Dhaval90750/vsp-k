# Brand

The VSp!k logo is a cut-paper wordmark: "VSp!k" in torn paper tiles, with a sharp red spike as the "!". Full guidelines are in [docs/01-brand-direction.md](../docs/01-brand-direction.md).

## Logo files: [`logo/`](logo/)

| File | Use |
|---|---|
| `vspik-logo.svg` / `.png` | Default, on light backgrounds |
| `vspik-logo-flat.svg` / `.png` | Print, invoices, proposals (no shadow) |
| `vspik-logo-on-dark.svg` / `.png` | Dark backgrounds |
| `vspik-logo-mono.svg` / `.png` | Single-colour uses |
| `vspik-icon.svg` / `.png` | App icon, favicon |
| `vspik-icon-square.svg` / `.png` | Instagram / LinkedIn profile picture |
| `vspik-icon-paper.svg` / `.png` | Icon on light backgrounds |

## Colours

| Name | Hex | Use |
|---|---|---|
| Ink | `#15171C` | Text, dark backgrounds |
| Paper | `#F3F0E8` | Main background |
| Card | `#FBFAF6` | Cards, tiles |
| Kraft | `#D9C7A7` | Paper tiles, accents |
| Signal | `#E5482B` | The "!" and the one main action |
| Signal (text) | `#B8341C` | Red text at body size |
| Volt | `#C8F031` | Occasional highlight, never as text on light backgrounds |

## Type

- **Headings:** Bricolage Grotesque 800
- **Body:** Instrument Sans
- **Labels:** JetBrains Mono

All three are free on Google Fonts.
